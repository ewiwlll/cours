Guide de Démarrage Rapide

Installez et configurez l'ensemble de l'environnement Cours (Revision OS) sur macOS ou Linux en une seule ligne de commande dans votre terminal.

Terminal 
curl -fsSL https://cours-awc.pages.dev/install.sh | bash
💡 Ce que fait le script automatiquement : 1. Détecte votre système d'exploitation et vérifie git et Node.js >= 18.
2. Clone le dépôt public officiel github.com/ewiwlll/cours.
3. Demande interactivement votre clé Gemini API directement dans la console pour l'écrire dans .env.
4. Installe la commande universelle cours dans votre PATH.
5. Compile le client Web Vite et prépare le module Mobile Expo.
6. Valide le moteur FSRS-5 par 23 tests unitaires et affiche le QR Code mobile.

Vue d'Ensemble & Commande CLI Globale (cours)

Plus besoin de naviguer dans les dossiers ni de taper des commandes compliquées. Où que vous soyez dans votre terminal, tapez simplement : 

cours

Cette commande démarre immédiatement le serveur backend, l'écouteur d'amphi, l'interface Web et affiche votre QR Code de synchronisation mobile.

Moteur FSRS-5 & Répétition Espacée Sans Chrono

L'algorithme officiel FSRS-5 calcule chaque jour votre pile de révision optimale basée sur trois variables :

Stabilité S (jours)

Durée en jours pour que la probabilité de rappel chute à 90%.

Difficulté D (1 à 10)

Complexité intrinsèque du concept, calibrée selon vos réponses.

Rétention R (%)

Probabilité prédite de souvenir à l'instant t : \(R = (1 + \text{Factor} \times t/S)^{\text{Power}}\).

⚡ Révision Sereine : Aucun compte à rebours stressant. Vous révisez à votre rythme naturel.

Synchronisation Mobile Instantanée & 4G Automatique

Deux modes de connexion simplifiés pour votre smartphone (Pixel 8 ou iPhone) :

📱 1. Wi-Fi Local (Chez vous / En cours)

Scannez le QR Code affiché dans votre terminal ou la modale paramètres : votre téléphone s'ouvre instantanément sur le serveur de votre Mac.

🌐 2. 4G Extérieur (Automatique via Tailscale)

Avec Tailscale activé, l'application détecte automatiquement votre URL HTTPS sécurisée et la partage à vos appareils sans configurer de box Internet.

Foire Aux Questions & Dépannage

Comment modifier ma clé Gemini après l'installation ?

Ouvrez l'application et cliquez sur l'icône ⚙️ Paramètres en haut à droite pour la mettre à jour et la tester en 1 clic.

Le port 3002 est déjà utilisé par une autre application ?

Changez simplement le port dans la modale Paramètres (ex: 3005) ou dans le fichier .env.

Comment fonctionne la synchronisation mobile en 4G à l'extérieur ?

L'application détecte automatiquement votre tunnel Tailscale (VPN privé gratuit) et fournit une URL HTTPS sécurisée accessible partout.
