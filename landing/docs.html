Guide de Démarrage Rapide

Installez et configurez l'ensemble de l'environnement Cours (Revision OS) sur macOS ou Linux en une seule ligne de commande dans votre terminal.

Terminal 
curl -fsSL https://cours-awc.pages.dev/install.sh | bash
💡 Ce que fait le script automatiquement : 1. Détecte votre système et installe l'application native /Applications/Cours.app.
2. Demande interactivement votre clé Gemini API pour l'écrire dans .env.
3. Installe la commande universelle cours dans votre terminal.
4. Compile le client Web Vite et active le mode PWA autonome.
5. Valide le moteur FSRS-5 par 23 tests unitaires et affiche le QR Code mobile.

Vue d'Ensemble & Commande CLI Globale (cours)

Plus besoin de naviguer dans les dossiers ni de taper des commandes compliquées. Où que vous soyez dans votre terminal, tapez simplement : 

cours

Cette commande démarre immédiatement le serveur backend, l'écouteur d'amphi, l'interface Web et affiche votre QR Code de synchronisation mobile.

cours Lance le serveur + interface
cours update Met à jour Git & Web
cours tailscale Configure l'accès 4G

✦ Super-Tuteur & Studio de Production

Le Studio Antigravity : Comment l'utiliser avec vos cours ?

Pour comprendre le fonctionnement de Cours, retenez cette distinction essentielle :

📱 L'Application Cours (Mac & Mobile)

C'est votre Cockpit de révision quotidien : enregistrement micro en amphi, pile de cartes FSRS-5 dues du jour, QCM diagnostiques et sas de rappel actif.

🧠 Le Studio Antigravity (Sur votre Mac)

C'est votre Studio de fabrication lourde & Super-Tuteur IA : il analyse vos amphis, génère les fiches KaTeX et fait progresser votre arbre de mémoire vivante.

🎁 Quotas Gratuits Google (0€ à vie) :

Antigravity fonctionne directement avec votre compte Google gratuit. Les quotas offerts sur le modèle gemini-3.7-flash sont extrêmement généreux et largement suffisants pour traiter tous vos amphis, générer des centaines de fiches et réviser toute l'année sans dépenser un centime.

Comment lancer Antigravity en 3 étapes :

  1. Ouvrez l'application Google Antigravity sur votre Mac.
  2. Faites File ➔ Open Folder et sélectionnez le dossier cours (ou votre dépôt cloné).
  3. Connectez votre compte Google si demandé (zéro clé payante nécessaire).

Les 3 phrases magiques à taper dans le chat Antigravity :

1. Pour compiler tous vos amphis enregistrés :

Traite tous mes enregistrements audio en attente et génère mes fiches de cours KaTeX avec les flashcards FSRS.

➔ Antigravity transcrit l'audio via Whisper Metal, structure les fiches avec LaTeX, tableaux « X vs Y » et initialise le sas de rappel actif.

2. Pour passer un oral blanc / interrogation personnalisée :

Fais-moi passer un oral blanc bienveillant sur la Photosynthèse, interroge-moi sur les pièges fréquents et évalue mes réponses.

➔ Antigravity prend le rôle d'un examinateur socratique, analyse votre restitution et met en avant vos points de vigilance.

3. Pour débloquer un doute ou une incompréhension :

Je n'ai pas compris la différence entre thylakoïdes et stroma, réexplique-moi avec une analogie concrète et crée une carte de rappel.

➔ Antigravity met à jour votre arbre de mémoire vivante (clarifications.json) et injecte une nouvelle flashcard dans votre pile du lendemain.

Le Sas de Rappel Actif Obligatoire (Active Recall Testing)

Dès qu'un cours est transcrit et structuré par Antigravity, la fiche brute reste initialement verrouillée.

🎯 Pourquoi ce sas obligatoire ?

La science cognitive démontre que la relecture passive procure une illusion de maîtrise immédiate mais un oubli massif à 48h. En obligeant l'étudiant à restituer le cours pendant 1 à 2 minutes sans aide, l'effort synaptique ancre les notions en mémoire à long terme.

Moteur FSRS-5 (Free Spaced Repetition Scheduler v5)

L'application abandonne les anciens algorithmes type SM-2 au profit de FSRS-5, le standard mathématique le plus précis de la répétition espacée.

Stabilité S Nombre de jours avant que la probabilité d'oubli n'atteigne 10%.
Difficulté D Complexité intrinsèque de la notion (de 1 à 10).
Rétention R Probabilité calculée de rappel immédiat : \( R(t) = (1 + 0.19 \cdot t / S)^{-0.5} \)

Concepts Atomiques Feynman & Tableaux « X vs Y »

Chaque fiche est rédigée selon la technique Feynman :

  • Analogie concrète en tête de chapitre pour matérialiser les mécanismes abstraits.
  • Tableaux comparatifs « X vs Y » pour éviter les confusions classiques (ex: Phase lumineuse vs Cycle de Calvin).
  • Callouts de pièges d'examen en rose pour identifier les distracteurs fréquents.

Mémoire Vivante des Questions (clarifications.json)

Quand vous posez une question ou butez sur une explication, le système enregistre l'incompréhension dans un arbre évolutif (data/revisions/clarifications.json).

🧠 Pourquoi c'est révolutionnaire ? Antigravity se souvient de vos difficultés passées. Il n'explique plus la même chose en boucle : il approfondit le raisonnement, propose un nouvel angle et crée une carte de déblocage automatique.

Synchronisation Mobile & 4G Tailscale

Vous pouvez réviser et enregistrer vos cours depuis votre smartphone (Pixel 8 ou iPhone) :

📶 À la maison (Wi-Fi Local)

Scannez simplement le QR Code de votre terminal ou de votre barre d'application. Votre téléphone se connecte directement à l'IP locale.

🌍 En amphi / transport (4G Tailscale)

Grâce à Tailscale, votre Mac et votre smartphone communiquent via un VPN privé chiffré sans ouvrir aucun port sur votre box.

FAQ & Dépannage

Comment mettre à jour Cours ?

Tapez simplement cours update dans votre terminal. Le script tire les dernières modifications de GitHub et recompile le client Web.

Mes données restent-elles privées ?

Oui. Tous vos audios, fiches de cours, photos et historiques FSRS-5 sont stockés localement sur votre disque dur dans le dossier data/.
