# Inbox & Archives de Transcriptions

Déposez ici les fichiers textes bruts (`.txt`, `.md`, `.srt`, `.vtt`, `.json`) issus des enregistrements d'amphi ou de dictaphones.

### Règles :
- La transcription originale est une **vérité source intouchable** : elle n'est jamais écrasée, tronquée ou remplacée par une synthèse IA.
- Le serveur et le watcher `automation.mjs` lisent ce dossier pour alimenter les cours et extraire les notions.
