# 👋 Bienvenue dans Cours (Revision OS) !

Votre environnement de révision et votre **Studio Antigravity** sont prêts.

---

## 🚀 Comment démarrer avec votre Super-Tuteur IA ?

1. **Ouvrez le chat Antigravity** à droite (ou appuyez sur ⌘ N).
2. **Tapez simplement ce mot magique** :
   ```text
   cours
   ```
   *(ou `fait tout`, `débloque`)*

3. **Votre agent s'occupe de tout** :
   - 🚀 **Mode « Fait Tout »** : Transcrit vos enregistrements amphi avec Whisper Metal (0€), génère les fiches KaTeX atomiques et crée vos flashcards FSRS.
   - 💡 **Débloquer une Notion / un Cours** : Vous pose des questions sur vos difficultés, explique avec une analogie Feynman concrète et ajoute automatiquement la carte de révision dans votre planning.
   - 🎙️ **Oral Blanc Bienveillant** : Vous interroge à l'oral sans chrono et évalue votre restitution.
   - 🔒 **Sas de Rappel Actif** : Valide votre restitution pour débloquer votre fiche.
